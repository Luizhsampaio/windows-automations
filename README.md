# Windows Automations

A collection of scripts and tools for automating Windows tasks, configurations, and everyday workflows. The repository brings together small, practical automations that can be adapted to individual Windows environments.

## Repository Contents

- [Restart-WindowsSearch.ps1](Restart-WindowsSearch.ps1) - Registers a Windows Task Scheduler task to run the SearchHost workaround at the current user's sign-in. Run the script once to set up or update the task; no manual Task Scheduler configuration is needed.
